- **Verse slide:** left evergreen panel 4.85" (eyebrow `THE THIRD ART · YASEEN NN / 83`, title, gold-italic Pickthall quote, Uthmani Arabic right-aligned, meta, watermark number) + gold-framed reserved plate on cream, hard gold edge; footer on every slide.

- Install **Playfair Display + Jost** (Google Fonts) for exact match; Georgia/Arial fallback is built in.

## 5. Production pipeline (per verse)

1. **Verse** — Uthmani text + Pickthall rendering verified against the codex ✔ (all 83 done)
2. **Calligraphy** — the ayah set in the frame, Uthmani script
3. **Thread Art** — panel executed in the Third Art thread practice, made for the verse
4. **Finish & frame** — gold-edge frame on cream paper, gallery finish
5. **Record** — photographed, polished, saved at 1× and 1.5× print masters

The pipeline advances **in batches of a movement**; each finished artwork drops
straight into its reserved slot in this deck (replace the plate image on the verse slide).
